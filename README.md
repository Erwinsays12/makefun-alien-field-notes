## What it does

`main.ts` writes one original one-line review of planet Earth, as left by an alien tourist, to `/output/entry.txt`. The line is fixed and deterministic, so every run produces the same text:

> Earth: free air, gorgeous sunsets, but checkout takes eighty years and the minibar is the entire ocean. Four stars — the sunsets are worth the eighty-year wait.

## Run

```sh
node main.ts
```

Requires Node 22.18 or later. No dependencies, no network access.
